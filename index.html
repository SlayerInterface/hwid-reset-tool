Features

Everything needed to wipe a hardware ban

One lightweight tool that covers identifiers, serials and residual tracing in a single pass.

🖥️

Full HWID reset

Regenerates machine GUIDs, SMBIOS tables and volume IDs so the system presents a completely fresh hardware fingerprint.

💽

Disk serial spoofing

Replaces physical drive serials and volume identifiers on HDDs and NVMe SSDs, hiding the signatures anti-cheats log.

🎮

GPU & MAC spoofing

Clones adapter descriptors and randomizes network adapter MAC addresses to break device-level correlation between sessions.

🧹

Trace cleanup

Purges registry leftovers, cached device records and anti-cheat trace files that re-link a banned account to the same machine.

🛡️

Safe restore points

Creates an automatic system restore point before every run, so all identifier changes can be reverted with one click.

⚡

Portable & fast

A single executable with no installer, no background services and no telemetry. The full reset completes in under a minute.

How it works

Three steps from banned to back online

No configuration files, no command line flags — just run it and reboot.

1

Download and run as administrator

Grab the latest build from gitscore.cc, extract the portable executable and launch it with elevated privileges so it can access hardware identifiers.

2

Spoof identifiers and clear traces

Select the targets you need — disk, GPU, MAC and SMBIOS — then let the tool generate new serials and wipe leftover anti-cheat tracing records.

3

Reboot and sign in

Restart Windows so the new hardware profile takes effect, then log into your account or create a fresh one on the reset machine.
